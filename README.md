# TSI · AI-Powered Full Stack Developer — Week 2: HTML & CSS Hands-On

Two 4-hour sessions of hands-on teaching material (Tech Skills Institute, Nepal).

| Folder | Session | Topics |
|---|---|---|
| `day1/` | Day 1 — HTML Core | How the web works, VS Code + Emmet, skeleton, text, lists, links & paths, images, tables, forms, validation |
| `day2/` | Day 2 — Semantic HTML, A11y, Media → CSS | Semantic layout, accessibility & meta, audio/video/iframe, CSS basics, selectors, colours/units, box model, display, styled Momo House site, Bootstrap teaser |

Inside each day:

- `START-HERE.md`: student setup (VS Code + Live Server + HTMLHint)
- `classwork/`: exercises (starter + `solution/` + `BUGS.md`)
- `homework/`: homework, with answers in `_solutions/`
- `notes/`: theory notes (Markdown)
- `instructor-demos/`: staged live code-along steps (`STEPS.md` per block)
- `deck/`: TSI slide deck (.pptx)
- `instructor-guide/`: guide (.md + .docx) and one-page run sheet
- `print/`: Word/PDF copies of notes, homework, classwork booklet; answer keys are in `print/instructor/`
- `_dist/`: ready-made zips (Student pack with no solutions, and Instructor pack)
- `00-plan/` (day1 only): the full plan for both days
