# D1-10 · Kathmandu gallery

**Time:** 7 min · **Type:** 🔨 Build · **Work:** alone

**Goal:** Build a small gallery with figures, an external link and a "back to top" link.

## Open it

Open `index.html` with Live Server (right-click → **Open with Live Server**).
No Live Server? Double-click the file. It opens in Chrome. Press F5 after each save.

## Your task

The pictures are ready in `images/`. Add:

- [ ] 2 `<figure>`s. Each has an `<img>` (with `src`, a good `alt` and `width="400"`) and a `<figcaption>`
  - `images/swayambhu.svg`
  - `images/patan-durbar.svg`
- [ ] 1 link to another website that opens in a **new tab**: `target="_blank"` (for example Kathmandu on Wikipedia)
- [ ] 1 "Back to top" link at the bottom: `<a href="#top">Back to top</a>`

**Show & tell:** after this, 2–3 pages go on the projector. Make yours worth showing!

## Done looks like

- Two pictures with captions under them.
- The Wikipedia link opens a new tab.
- "Back to top" jumps to the top (make the window small to test it).
- HTMLHint: 0 problems. You will audit this folder again in **D1-16**.

## Stuck?

1. `alt` = what you would say about the picture over the phone.
2. `<figure>` is the box; `<img>` and `<figcaption>` go inside it.
3. `#top` is special: every page has a top, so you don't need an `id` for it.
