# D1-03 · Skeleton from memory

**Time:** 4 min · **Type:** 🔨 Build · **Work:** alone

**Goal:** Type the whole HTML skeleton from memory. No Emmet, no notes.

## Open it

Open `index.html` with Live Server (right-click → **Open with Live Server**).
No Live Server? Double-click the file. It opens in Chrome. Press F5 after each save.

## Your task

**Close your notes. Don't use `!`.** Type every line yourself in the empty `index.html`:

1. The DOCTYPE line
2. `<html>` with the language attribute
3. `<head>` with: meta charset, meta viewport, title
4. `<body>` with one `<h1>` and one `<p>`
5. Close everything (last box opened, first box closed)

**Wrong is fine. Blank is not.** Then open the page with Live Server and check it against your notes.

## Done looks like

- The tab shows your title.
- The page shows your heading and paragraph.
- The Problems panel (Ctrl+Shift+M) shows 0 problems.

## Stuck?

1. Start with the boxes: `<html>`, then `<head>` and `<body>` inside it. Fill them after.
2. Can't remember the meta lines? Write the ones you remember. Check them later.
3. After 4 minutes, open `notes/03-html-skeleton-and-anatomy.md` and correct your file. Mark what you forgot.

## Fast?

Delete everything and type it again. Can you do it in under 90 seconds?
