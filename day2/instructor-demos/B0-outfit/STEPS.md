# B0 · Same skeleton, new outfit — demo steps

**When:** 0:00–0:07 (D2-00 follows) · **Analogy:** **Skeleton & outfit** (the CSS Zen Garden idea)

Open `W2D2/instructor-demos/B0-outfit/` in VS Code and start Live Server on the step you are typing in. Each `step-NN-*` folder is the **finished state after step NN**. If the live typing goes wrong, open the next step folder and carry on.

## Step 01 · the bare skeleton (`step-01-no-css/`)

**In `index.html`, type:**

```html
<!-- no <link> in <head>: this page has no CSS at all -->
```

**Emmet:** —

**Point at:** Times New Roman, blue underlined links, everything on the left. This is HTML with no outfit.

**Say this:** "This is yesterday's work: a good skeleton. It is correct, but it is wearing nothing."

## Step 02 · three outfits, one skeleton (`step-02-three-outfits/`)

**In `index.html`, type:**

```html
<link rel="stylesheet" href="css/outfit-traditional.css">
```

**Emmet:** `link:css` + Tab, then change the href

**Point at:** Save, look. Then change only the href to `outfit-modern.css`, save. Then `outfit-night.css`, save.

**Say this:** "I changed one word. The HTML did not change at all. Same skeleton, new outfit. Today you learn to sew the outfit."

**Then:** students do **D2-00** (3 min). Volunteer homework spot-check while they swap.
