# D2-11 · Theme the canteen menu

**Time:** 5 min · **Type:** ✏️ Modify

**Goal:** Dress the canteen menu in the TSI palette, with a safe font stack, rem sizes and readable line height.

Open `index.html` with Live Server (right-click → **Open with Live Server**). No Live Server? Double-click the file and press F5 after each save.

## Task

- [ ] **Palette:** cream `#FDF6EC` page background, navy `#14213D` text, cherry `#990011` for h1 and h2.
- [ ] **Font stack:** replace `"Times New Roman"` with `"Segoe UI", Tahoma, Arial, sans-serif`.
- [ ] **rem sizes:** body `16px` → `1rem`, h1 `40px` → `2.5rem`, h2 `24px` → `1.5rem`, `.note` `14px` → `0.875rem`.
- [ ] **Line height:** add `line-height: 1.6;` to `body`.
- [ ] **Bonus:** give the table header (`th`) a navy background and cream text.

> **Paint shop** (colours) and **measuring tape** (units): pick from the shop, measure with the tape.

## Done looks like

A cream page with navy text, cherry headings, a sans-serif font, comfortable line spacing, and no `px` font sizes left.

## Stuck?

1. rem = "times the root size". The root is 16px, so `1.5rem` = 24px.
2. A colour does not show? Check the `#` and the 6 characters.
3. Font still looks like Times? Each font name with a space needs quotes, and names are separated by commas.
