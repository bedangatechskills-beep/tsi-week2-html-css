# D1-00 · Setup check

**Time:** 8 min · **Type:** 🔨 Build · **Work:** alone

**Goal:** Open the pack in VS Code, see your page live, and open F12.

## Open it

Open `index.html` with Live Server (right-click → **Open with Live Server**).
No Live Server? Double-click the file. It opens in Chrome. Press F5 after each save.

## Your task

1. Open VS Code. Click **File → Open Folder…** and choose the **`W2D1`** folder. Click **Select Folder**.
   (Open the *folder*, not a single file. Then all the links and tools work.)
2. In the Explorer on the left, open `classwork/D1-00-setup-check/index.html`.
3. Right-click inside the code → **Open with Live Server**. Chrome opens the page.
4. In VS Code, change `Student` in the `<h1>` to **your own name**.
5. Press **Ctrl+S** to save. Look at Chrome: the page reloads by itself.
6. In Chrome, press **F12**. Click the **Elements** tab. Find your `<h1>` with your name in it.
7. Put VS Code and Chrome side by side (Win+← and Win+→). You will work like this all day.

## Done looks like

- Chrome shows "Namaste! My name is **your name**".
- You saved once and the page changed **without** pressing F5 (Live Server).
- F12 → Elements shows your `<h1>`.

## Stuck?

1. No **Open with Live Server** in the menu? Use the fallback: double-click `index.html` in Windows Explorer. It opens in Chrome. After each save, press **F5**. Install Live Server at the break (see `START-HERE.md`).
2. The page did not change? Check the dot on the VS Code tab. A white dot means "not saved". Press Ctrl+S.
3. Still stuck? Raise your hand. One install problem must not stop you. Use the fallback and keep going.

## Fast?

Read `START-HERE.md` again and check that **HTMLHint** is installed. You need it from block B3.
