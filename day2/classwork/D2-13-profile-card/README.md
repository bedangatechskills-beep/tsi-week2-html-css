# D2-13 · Profile card

**Time:** 7 min · **Type:** 🔨 Build

**Goal:** Build a centred profile card for Sunita with the box model. Then show it on the projector.

Open `index.html` with Live Server (right-click → **Open with Live Server**). No Live Server? Double-click the file and press F5 after each save.

## Task

- [ ] `.card`: `width: 320px;` and `margin: 0 auto;` (centred)
- [ ] `.card`: `padding` (try `24px`) and a `border` (width, style, colour)
- [ ] `.card`: `border-radius` (try `16px`) and a white `background-color`
- [ ] `.card`: `box-sizing: border-box;` (the card stays exactly 320 px wide)
- [ ] `.avatar`: equal `width` and `height` (120 px) and `border-radius: 50%;` (round)
- [ ] `body`: a soft background colour, so the white card stands out
- [ ] **Bonus:** a coloured ring around the avatar, `text-align: center`, your own colours

## Done looks like

A white card with rounded corners in the middle of the page, a round photo, and the text centred. In F12, the card measures exactly 320 px wide. **Show & tell:** 2–3 cards go on the projector.

## Stuck?

1. Card stuck on the left? `margin: 0 auto` needs a `width`.
2. Photo is an oval? Width and height must be the same.
3. Card wider than 320 px in F12? You forgot `box-sizing: border-box`.
