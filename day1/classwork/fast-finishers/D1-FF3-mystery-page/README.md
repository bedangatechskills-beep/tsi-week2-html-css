# D1-FF3 · Mystery page

**Time:** 15 min · **Type:** 🔨 Build · **Work:** alone

**Goal:** Rebuild a page from a picture: choose the right tag for each part.

## Open it

Open `index.html` with Live Server (right-click → **Open with Live Server**).
No Live Server? Double-click the file. It opens in Chrome. Press F5 after each save.

## Your task

Open `target.svg` in Chrome (drag it into a tab, or right-click → Open with Live Server). It is a **picture** of a web page.
Rebuild it in `index.html`:

- [ ] the `<title>` and the `<h1>`
- [ ] Didi's picture: `images/chef-didi.svg`, `width="150"`, with a good `alt`
- [ ] two lists: which one is a `<ul>` and which is an `<ol>`?
- [ ] the price table: Item | Price, with a header row
- [ ] the link "Visit Momo House": link it to `../../D1-15-momo-house-repair/index.html`

The table lines: copy the `<style>` block from `classwork/D1-11-broken-timetable/index.html` into your `<head>`.

## Done looks like

- Put your page and `target.svg` side by side. Same text, same order, same kinds of tags.

## Stuck?

1. Look at the shapes: bullets = `ul`, numbers = `ol`, a grid = `table`.
2. Bold, centred cells in a table = `th`.
3. Build top to bottom. Save and compare after each part.
