# D2-HW2 · Style your portfolio

**Time:** about 1.5 h (at home, if you can; HW1 and HW3 come first) · **Type:** 🔨 Build

**Goal:** Take a page you made yourself and make it semantic, accessible, and dressed in one shared stylesheet.

## Start from

Pick **one**:
- your Week 1 **About Me** page, or
- your **D1-10 Kathmandu gallery** from Day 1.

Copy it into a new folder `my-portfolio/` inside `W2D2/homework/D2-HW2-style-your-portfolio/`. Make a second page
(for example `about.html` or `projects.html`) so you have **2 pages that share one stylesheet**.

## Task

1. **Semantic skeleton:** replace `div`s with `header`, `nav`, `main`, `section`/`article`, `footer`. One `<main>` per page.
2. **Accessible:** `lang="en"`, a real `<title>`, alt on every image, a label on every input, no heading jumps.
3. **One stylesheet:** create `css/style.css` and link it from **both** pages (the school uniform).
4. **Style it** with everything from today: a 3-colour hex palette, a font stack with a fallback, `rem` sizes,
   `line-height`, a horizontal nav, one box-model card, a `:hover` state.
5. Go through `CHECKLIST.md`: all 12 items.

## Done looks like

Both pages look like one website. HTMLHint shows no problems. Lighthouse Accessibility is 90 or more. You can explain
every line of your CSS (the One Rule).
